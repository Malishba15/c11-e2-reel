# C11 ya E-2? — Pehle yeh check karein

A 60-second vertical reel (9:16, 1080×1920) for Vanguard Global Migration.

| File | What it is |
|---|---|
| `C11_vs_E2_reel_captioned.mp4` | Final reel with burned-in Roman Urdu/English captions and music |
| `C11_vs_E2_reel_clean.mp4` | Same reel without voiceover captions, for adding an ElevenLabs VO and CapCut captions |
| `voiceover_captions.srt` | Voiceover script with timings |
| `make_video.py` | Generator script (needs Python 3, Pillow, NumPy, ffmpeg, and Montserrat + Playfair Display fonts in `fonts/`) |
